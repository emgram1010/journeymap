# User Language Guide

> Internal terms are for agents and engineers. Operators need plain operational language.

---

| Internal Term | User-Facing Term |
|---|---|
| Journey map | Your operating map |
| Stage | Step |
| Lens | Person/team perspective |
| Cell | Detail for this step |
| Runtime engine | Watcher |
| Conformance check | Did reality match the plan? |
| Constraint | Rule |
| Hard constraint | Blocking rule |
| Soft constraint | Warning rule |
| Completion signal | Proof this step is done |
| Leakage | Money leaking from the process |
| Measurement frequency | How often this happens |
| Cost rate | What this person's time costs |
| Stage cost component | Other cost to run this step |

---

## Cost Component Language

Never use logistics nouns in the product model.

Use:
- execution cost
- per-event cost
- consumption cost
- variance cost

Avoid:
- fuel
- mileage
- vehicle wear
- route cost
