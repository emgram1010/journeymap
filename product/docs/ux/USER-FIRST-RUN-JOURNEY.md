# User First-Run Journey

> The operator should never feel like they are configuring software.

---

## First 10–20 Minutes

```text
1. User says what operation they run
2. AI identifies the unit of work: per job, per call, per client, per case
3. AI zooms into one painful step
4. AI asks for frequency, real duration, target duration, and actor cost
5. AI builds a lightweight L3 atomic map
6. AI runs leakage math
7. AI shows cost per event, annual cost, and 3-year cost of inaction
8. User chooses: refine map, create scenario, or prepare for runtime monitoring
```

---

## User-Facing Language

Say:
- “step” instead of `stage`
- “person/team doing the work” instead of `actor lens`
- “what proves this is done?” instead of `completion_signal`
- “rules this step must follow” instead of `constraints_ok`
- “money leaking from this step” instead of `leakage_delta`

Do not say:
- webhook
- JSON
- stage key
- constraint schema
- automation snapshot
